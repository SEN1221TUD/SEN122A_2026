This folder contains the practical exam of 2023. It can be used to familiarise yourself with the exam format and the type of questions that can be asked. For multiple choice questions, "**" indicates the correct answer.

Note 1: The HTML file does not display on GitHub website. To see it, download the file and open it with a browser (or look at the pdf).

Note 2: Be aware that the biogeme syntax used in the exam in 2023 differs slightly from the biogeme version and methods used in this year's course.

Note 3: Question 12 was intended to have one correct answer, but it was found that two answers could be considered correct.
